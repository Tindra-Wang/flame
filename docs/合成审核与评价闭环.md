# 合成、审核与评价闭环

## 场景覆盖

目前以房间火灾、林区/室外火灾两个基础类型为主，可保存不同布局、燃烧物、起火点、通风和求解配置。名称不同不代表独立工况。现有覆盖适合流程验证，不能代表全部应急消防场景。

建议下一批重点补充：房间家具、走廊/门窗通风、仓储堆物，以及室外植被疏密与风场变化。新增几何/燃料/通风需重新求解FDS；同一工况的机位、视觉天气、曝光与扩散变体复用场数据。雨雪目前仅视觉条件。当前版本增加覆盖统计接口，不将尚未建立的模板列为已支持。

## 页内审核与Label Studio

主平台“样本与标注”选择批次，查看候选框与自动质量状态，点击“页内连续审核”即可修订、通过或剔除并切换下一张。仅使用主平台账户；产品经理、测试师有审核权限。

点击“连接并同步Label Studio”后，后端使用现有服务凭据创建任务、同步候选预测，并推送已经存在的人工审核。令牌不进入浏览器。后续页内审核先保存到平台，再发起后台同步；服务不可用时保留审核与待同步计数，点击同步可重试。新修订更新同一条远程标注，不重复新建；遇到远程标签修改则阻止覆盖，先回导并确认。

平台保存实际审核人、时间、图片哈希和修订；Label Studio服务账户代表API提交者，不冒充平台审核人的Label Studio账户。剔除记录在远端标记为跳过，不作为无火真值。完整Label Studio工具作为可选外部入口，仍遵循它自身的登录；本次没有实现两个产品的SSO，也没有将服务令牌注入iframe。

采用原生框选组件与后台API，是为当前单类火焰框审核提供页内工作流；不是将完整Label Studio前端移植进主平台。独立LSF分发已被官方弃用，参考[官方说明](https://labelstud.io/guide/frontend.html)。同步使用[创建标注](https://api.labelstud.io/api-reference/api-reference/annotations/create)、[更新标注](https://api.labelstud.io/api-reference/api-reference/annotations/update)及[包含未标注任务的导出](https://labelstud.io/guide/export.html)接口。

## 数据路径

生成批次 → 候选标注与自动检查 → 页内人工审核/Label Studio同步 → 固定评价输入或DVC版本 → 分布比较/检测对照。

生成、标注和审核共用Run与sample_id，增强图保留parent_id、工况group_id及条件元数据。“样本与标注”上方显示批次候选、自动通过、待审核、人工通过、剔除及处理进度；自动通过不会变成人工通过。

## 分布评价

“效果评价→分布相似度”选择真实批次与物理/扩散合成批次，选择基础原图、扩散图或两者。提交时只复制人工通过且结构有效的图像，冻结审核、清单和哈希，避免未审核、拒绝或baseline对照图混入。真实/合成重复图像会被拒绝。FID依赖公开Inception特征；若权重不可用则报失败，不替换成颜色指标。颜色JS为独立的快速诊断选项，明确不叫FID。

每组2张是运行下限，不是可信评价规模。记录特征维度、数量和样本范围；不同维度不能横比。可对同一真实参照分别比较原图与增强图；当前尚未自动做按天气/机位的分层FID或火焰ROI评价。用于生成调参的真实参照与最终检测测试集应分开管理。

## 检测提升对照

“效果评价→检测提升对照”选择一个纯真实数据DVC版本和一个合成DVC版本。真实版本必须有独立train/val/test，合成版本必须有train。后端校验图像/标签/审核和版本哈希，并检查来源组与精确图像重复；来源事件标识仍需人工正确登记，不能把同一视频重复导入为不同事件。

复用已有YOLO成对训练逻辑，A仅真实，B真实加合成。两组从同一公开初始权重启动，使用相同真实val/test、种子、输入尺寸和批量；A重复采样训练图，使两组训练列表长度和更新预算一致。实际更新次数不一致时禁止形成有效对照报告。默认5轮只是小规模试验，可通过接口调整epochs、batch、imgsz、seed。

任务由现有Worker/GPU容器运行，支持查看日志、取消和重试。完成且通过来源/指标/预算校验后，页面显示mAP50、mAP50–95、Precision、Recall的A/B条形对照及差值（百分点）；下降显示负值。零基线的相对提升未定义时保留空值。没有运行结果就显示缺少数据，不填示例分数。

当前没有独立真实训练/测试数据，尚未执行本项目真实火焰收益实验，也不保证加入合成数据必然提升。多种子重复实验、真实材料/光学标定和事件来源核查仍是算法评价工作。

## 接口

- `GET /api/projects/{project}/workflow`：场景条件与批次处理统计。
- `GET /api/runs/{run}/label-studio`：连接状态和待同步人工修订数。
- `POST /api/runs/{run}/review`：保存页内人工审核，不依赖Label Studio在线。
- `POST /api/runs/{run}/label-studio/push`：后台连接、幂等推送与失败重试。
- `POST /api/runs/{run}/label-studio/pull`：回导外部已完成人工标注。
- `GET /api/projects/{project}/evaluations/capabilities`：已安装检测权重。
- `POST /api/projects/{project}/evaluations/distribution`：real_run、synthetic_run、selection、metric、dims。
- `POST /api/projects/{project}/evaluations/detector-comparisons`：real_version、synthetic_version、weights、epochs、batch、imgsz、seed。
- 原有任务、实验记录和版本导出接口继续使用；OpenAPI位于`/docs`。

重算法不在Web请求中执行。纯数据准备在`fire_modeling/evaluation_data.py`，训练执行在`learning.py`；应用接口在`platform_api/workflow.py`，Label Studio桥接在`label_bridge.py`。不增加新数据库、消息队列或账户体系。
