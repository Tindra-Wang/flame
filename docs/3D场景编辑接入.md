# 3D场景编辑接入

入口：主平台“仿真与合成”→“打开完整3D场景编辑器”。同源独立页面共用主平台账户、项目、场景和任务。

当前使用原版物体、场景、渲染和作业标签。旧版自行添加的右下作业面板已经移除。操作、引擎路线、MP4续跑和实测证据见[原版编辑器迁移与执行链路](原版编辑器迁移与执行链路.md)。

启动运行`scripts/start-platform.ps1`，自动构建编辑页。首次需要简化模型时运行`scripts/build-scene-models.ps1`。Linux/CI安装`integrations/firephantom/web`依赖，运行Vite并指定`scene-editor/vite.config.mjs`，再构建主前端。

模型目录有161项定义；本地提供5个自建简模，其余缺失网格明确显示“燃料盒”，可上传GLB补充。FDS使用网格对齐包围盒，Blender使用详细网格，两者不是同精度几何。FDS采用等效燃料和规定热释放率，尚未实现真实材料热解、自主蔓延或独立AI走势预测。真实数据评价及物理标定仍待完成。
