# FDS时序与训练数据链路

主流程：3D场景 → FDS求解 → 三维场交接 → Blender基础渲染 → 受控生成增强 → 标注与质检 → 人工审核 → DVC版本及导出 → 独立模型评价。

## 当前升级

室外40×40×20米场景若使用0.2米网格会产生400万个单元，超过本机上限。渲染设置现在显示推荐网格、预计单元数并允许手动选择；该场景推荐0.8米、62,500格。网格选择只进入本次作业，不偷偷重写已保存场景。粗网格会影响火源吸附、尺寸和细节，精细研究需缩小计算域。缩短求解时长不能降低网格数量。

编辑器默认FDS路线。顶部开始作业后，仍在编辑器“作业”内选择任务、点击“观看MP4”；原版分组结果抽屉及其视频也保留。任务中心只是跨场景管理入口。

FDS求解时长默认20秒，可设置3至60秒，且必须长于火源增长时间；默认采样24个时间点。三维切片使用`DT_SL3D`控制输出间隔，二维切片使用`DT_SLCF`，两者不能混用。导出在真实求解时刻间采样，不生成不存在的物理帧。

播放时显示当前真实求解时刻、HRRPUV加权燃烧重心XYZ、最高温度、反应区体积、峰值热释放率密度及俯视重心轨迹。反应区阈值为1 kW/m³；重心不是最外层火焰前沿，体积基于离散网格计数。坐标单位为米，Z向上。参数来自FDS场，与材质亮度分离。

MP4播放器按编码后的帧切换时间映射物理参数，保留原始求解时间；12fps只是播放编码率。重复保持某一物理帧不会新增训练观测。FDS结束并完成三维场导出后，编辑器能先读取物理参数，再等待渲染；当前未实现FDS仍在求解时逐步推送场数据。

## “预测下一步”分三种情况

- FDS继续求解：在既定初边界条件下计算下一时刻物理场，是数值模拟。
- 当前短时外推：仅用截至当前时刻连续3帧重心估算速度，预测一个采样间隔后的重心；没有训练，页面明确标注“基线”。无燃烧区域或历史不足则不给出预测。
- 后续训练模型：历史图像及物理状态作为输入，未见过的下一时刻FDS状态作为仿真监督目标，学习更复杂的时空变化。需要独立评价后才能报告预测效果。

当前基线预测的是燃烧重心变化，不能代表火势蔓延、引燃新物体或真实应急决策。现有FDS采用规定热释放率、等效燃料和包围盒近似，尚无经过实验标定的真实材料热解/自主蔓延模型。

## “用于后面大模型训练”是什么意思

这里首先是在生产训练数据，并不是已经训练了大模型。一个时序样本可组织为：同一工况的过去3帧图像＋时刻/工况/物理参数 → 下一帧及对应物理参数。若训练多模态模型，还需补充适合任务的指令、问答及人工核对；若训练时序预测器，可直接使用数值序列。只有单张检测图片和框，不足以训练火势时序预测。

页内“导出时序训练数据”提供`ai07.temporal-training.v1`：作业/场景/修订、每帧时间及物理值、场哈希、视频帧对应关系和3→1训练窗口索引。`forecast`只作为未训练基线，不能作为监督真值；下一时刻FDS观测才是仿真目标。原始NPZ、RGB、掩码和配置保留在该作业目录，JSON是索引与参数清单，并非包含全部媒体的训练包。

同一工况、多机位及增强派生图必须按共同来源组划分训练/验证/测试集，不能逐图随机拆分。多工况、多火源、多通风条件的数据覆盖、真实数据及人工参照、模型训练和最终泛化评价仍需后续完成。

## CFD＋燃烧模型＋生成式AI如何衔接

FDS产生真实数值场 → Blender把温度/烟炱/热释放率映射为画面，并输出候选掩码 → 扩散模型丰富外观和背景 → 保留父图/掩码/模型版本/种子 → 检查新图标签 → 人工审核。

新增“数据合成”入口已调用SD1.5掩膜inpainting，支持背景与火焰外观两模式，输出同源深度并记录派生标签。旧任务保留img2img保护区路径。ControlNet适配器已接入但本机权重未安装，未宣称实际运行。已有模型过滤器拒绝记录保留，不以关闭过滤器获得成功结果。07中的Diffusion/GAN是方法选项，本项目使用Diffusion，不要求同时新增GAN。

增强图适用于外观和检测训练，不应作为新的CFD状态或物理真值。单帧独立扩散可能闪烁，未经时序一致性校验的增强帧不能直接冒充连续预测序列。物理时序训练优先使用原始FDS渲染。

## 同步补齐的四个环节

- 基础渲染：现有Blender体积渲染已执行；进一步检查体积取值、颜色/消光/发光映射和曝光，以同一物理帧固定相机做前后对照，再调整分辨率、采样。光学参数未标定，不把温度直接等同于图像亮度，不以提高采样冒充校准。
- 物理场交接：已有FDS三维温度、烟炱、HRRPUV → XYZ/单位契约 → NPZ/OpenVDB → Blender，并校验场、场景版本和模型哈希；本轮修复三维采样间隔。几何精度和真实材料参数校准尚待完成。
- 受控增强：已实现真实mask inpainting、同源深度、火焰外观增强、新候选掩码和区域保护检查，并完成8张原图/16张增强图实跑。ControlNet权重安装、人工标签精度及时间一致性评价未完成，见[实现与验证](受控合成实现与验证.md)。
- 数据价值评价：固定独立真实测试集，比较仅真实数据与真实＋合成数据，控制相同模型、训练设置、数据来源划分并报告检测指标。当前没有独立真实数据，不能给出真实提升结论；FID或观感不能替代检测收益评价。

## 接口

- `POST /api/projects/{project}/scene-editor/generate`：`generation.engine=fds`、`duration_s`、`frame_count`。
- `GET /api/projects/{project}/scene-editor/compat/jobs/{id}/trajectory`：物理时序及因果基线；未完成返回明确等待状态。
- 同接口`?download=true`：下载时序训练清单；场未导出时拒绝下载。
- `GET /api/simulation-videos/{id}`：视频、源帧物理时间、编码切换时间及机位。

算法模块负责物理参数与基线，API负责权限/来源校验，播放器只负责呈现与时间同步；不把物理计算塞进页面。扩散增强继续使用独立阶段，不重算FDS。
