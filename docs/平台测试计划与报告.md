# 平台测试计划与报告

日期：2026-10-21。范围为现有算法流水线与新增统一Web平台。SRS及其验收阈值保持不变。

## 计划与判定

- 单元与接口：参数校验、权限与项目隔离、幂等队列、取消重试、工作进程鉴权和实际产物门禁、标注审核、DVC发布与导出、真实数据导入、评价计算、秘密保护及文件路径约束。
- 集成：使用独立小工况运行FDS→Blender→SD1.5，并将产物同步到独立Label Studio项目；不将候选预测当成人工标签。
- 前端：TypeScript检查及生产构建；浏览器检查桌面与390px移动端、导航、实际样本、键盘框编辑、登录弹窗焦点和退出。
- 判定：测试无失败且代码覆盖率≥70%；课程算法验收仍需独立真实图像、人工标签、物理参照与检测对照试验。

```powershell
npm ci
npm run build
```
