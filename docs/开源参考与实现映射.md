# AI-07 开源参考与实现映射

日期：2026-10-18。用户指定可参考下列项目。当前实现复用本项目已有算法，不复制这些仓库的代码、不安装其完整依赖树，不将其论文或数据集效果当作本项目实测结果。

- [AIS-Clemson/FLAME_SD](https://github.com/AIS-Clemson/FLAME_SD)：参考掩膜引导、火焰位置控制和训练外生成思路。平台记录SD增强父图、随机种子、模型版本与人工重审状态。当前是SD1.5 img2img，尚未移植FLAME Diffuser的掩膜引导算法；仓库可见文件未给出清晰的整体LICENSE，复制代码前须逐文件核对并取得适用授权。
- [usnistgov/FD-Gen](https://github.com/usnistgov/FD-Gen)：参考参数化FDS工况、HRR、通风和批处理组织。平台使用现有SceneConfig及FDS适配器。上游[LICENSE.md](https://github.com/usnistgov/FD-Gen/blob/main/LICENSE.md)包含NIST软件许可说明；不把可查看源码等同于无条件使用其依赖和示例资产。
- [DLR-RM/BlenderProc](https://github.com/DLR-RM/BlenderProc)：参考批量渲染、相机采样、RGB/分割及COCO导出分层。平台仍调用已有Blender脚本；上游[LICENSE](https://github.com/DLR-RM/BlenderProc/blob/main/LICENSE)及外部模型/材质授权分别核对。没有为借鉴框架而额外下载其场景资产。
- [pyronear/pyro-dataset](https://github.com/pyronear/pyro-dataset)：参考野火数据整理、来源元数据与数据流水线组织。按本项目SRS实现同源分组及增强父图防泄漏，不声称上游每一项防泄漏规则已原样移植。各数据源许可证独立登记，不假定仓库许可覆盖所有图像。
- [HumanSignal/label-studio](https://github.com/HumanSignal/label-studio)：实际采用1.22.0容器、真实项目及任务API，服务令牌只在后端持有。遵循上游Apache-2.0许可和NOTICE要求。
- [iterative/dvc](https://github.com/iterative/dvc)：实际执行DVC add/push及Git提交，当前remote在项目本地卷内，不宣称是异机备份。DVC使用Apache-2.0许可；公开预训练模型的许可另行记录。

统一平台的适配边界为：Vue页面 → FastAPI应用服务 → 持久任务队列 / 独立Worker → FDS、Blender、SD容器；人工审核 → DVC/Git研究快照 → COCO/YOLO → 独立评价。引擎通过配置和清单交接，第三方仓库不直接侵入项目、审核与版本领域。

实现依据的官方接口说明：[Label Studio API](https://labelstud.io/guide/api)、[服务启动环境变量](https://labelstud.io/guide/start)、[DVC add](https://doc.dvc.org/command-reference/add)、[FastAPI容器部署](https://fastapi.tiangolo.com/deployment/docker/)。
